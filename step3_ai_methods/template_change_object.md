# Объект изменений — шаблон (вход в проектную работу Шага 4)

1. **Ось:** продукт / процесс / бизнес-инициатива (выбрать одну)
2. **Объект:** что конкретно меняем: …
3. **Проблема** (языком блока/территории): что не так и для кого: …
4. **Чем подтверждено:** данные/отклонения, где это видно (метрики, периоды): …
5. **Проверка на ошибки интерпретации:**
   - Корреляция не выдана за причинность? …
   - База сравнения корректна (сезонность, сопоставимый период)? …
   - Это не «ложный всплеск» (разовое событие)? …

## Чек-лист
- [ ] Объект один и конкретный
- [ ] Проблема подтверждена данными, не ощущением
- [ ] Названы 1–2 метрики, где проблема видна
- [ ] Выдерживает вопрос «почему вы решили, что причина в этом?»
