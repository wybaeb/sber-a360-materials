# Промпт: автоматический EDA через ИИ (слайд 4 презентации M2)

Используйте в ИИ-ассистенте с исполнением кода (рабочее пространство / Colab / ChatGPT Code Interpreter). Прикрепите `synthetic_sales.csv`.

```
Ты — аналитик данных. Проведи разведочный анализ (EDA) приложенного датасета
продаж. Веди трассируемые рассуждения: перед каждым блоком кода объясняй, что и
зачем делаешь, после — комментируй вывод.

Пройди по шагам:
1. Загрузка и осмотр: head, info, dtypes, describe; приведи даты к datetime.
2. Пропуски и дубликаты: посчитай, удали дубли по order_id, реши, что делать с пропусками.
3. Распределения: гистограммы revenue/price/quantity с медианой, boxplot по категориям.
4. Выбросы: метод IQR (Q1,Q3,границы ±1.5·IQR) + z-score; прими ОСОЗНАННОЕ решение,
   что отсечь, а что — реальные бизнес-данные. Отдельно проверь отрицательные цены.
5. Корреляции: матрица + оговорка «корреляция ≠ причинность».
6. Сезонность: помесячная выручка/заказы/средний чек (resample), паттерны по дням недели.
7. Воронка по покупкам (1→N) и каналы: где наибольшее сужение; метрики по каналам.

В конце — таблица из ≥5 гипотез: гипотеза / что проверить / какое действие.
Не принимай выводы слепо: проверяй на нескольких строках вручную и пиши, где
результат требует перепроверки.
```
