# Презентация аналитического проекта — каркас (5–7 слайдов)

Каркас: **проблема → метрика → данные → инструмент → анализ → вывод → эффект**

1. **Проблема.** Объект изменений (продукт/процесс/бизнес-инициатива) и проблема, подтверждённая данными (из Шага 3).
2. **Метрики.** Дерево метрик: опережающие → запаздывающие; 1–2 ключевые метрики проекта.
3. **Данные.** Что уже есть (карта источников Шага 1), чего не хватает и как будем собирать.
4. **Инструмент.** Excel / BI (Навигатор) / GigaChat / Python — и почему так (рамка Шага 2).
5. **Анализ.** Что сделали/сделаем; проверка на ошибки интерпретации (Шаг 3).
6. **Вывод.** Факты vs интерпретации vs гипотезы — что утверждаем и с какой уверенностью.
7. **Эффект для бизнеса.** Финмодель: ожидаемый эффект, допущения, чувствительность.

## Чек-лист
- [ ] В дереве есть опережающие И запаздывающие метрики
- [ ] По каждой метрике понятно, откуда данные
- [ ] Эффект посчитан на данных, которые реально планируется собирать
- [ ] Допущения выписаны, чувствительность проверена
- [ ] 5–7 слайдов, каркас соблюдён
