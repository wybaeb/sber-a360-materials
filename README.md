# Сбер · «Аналитика 360» — материалы для участников (Шаги 1–4, Карпов Курсы)

Учебные материалы к четырём встречам Карпов Курсы корпоративной программы Сбера
«Аналитика 360». Одна папка = один шаг программы:

| Папка | Шаг | Практическое задание |
|---|---|---|
| `step1_data_landscape/` | 1. Ландшафт данных и карта источников | список источников данных по своему подразделению |
| `step2_tools_bi/` | 2. Инструменты анализа и BI-дашборды | сформулировать задачу для GigaChat |
| `step3_ai_methods/` | 3. AI-инструменты и базовые методы анализа | выбрать объект изменений и зафиксировать проблему |
| `step4_project/` | 4. Выбор объекта изменений и запуск проекта | презентация проекта с деревом метрик и финмоделью |

## Учебный OnePager

`onepager/index.html` — одна страница на весь курс: маршрут четырёх артефактов (карта источников →
задача для GigaChat → объект изменений → презентация проекта), материалы и датасеты по шагам и
**образцы промптов по этапам обработки данных** (постановка задачи, карта источников, загрузка и
осмотр, очистка, агрегация, EDA, сегментация, проверка отклонения, дерево метрик, финмодель,
сборка презентации). Каждый промпт — с блоком «что проверить в ответе». Открывается прямо на встрече.

## Про ИИ-ассистент
Демо в ноутбуках инструментонезависимы: промпты работают в **GigaChat** (основной инструмент
программы) и любом другом ассистенте. Где в коде нужен ключ ИИ-провайдера — он берётся из
переменных окружения (`AI_PROVIDER_URL`, `AI_PROVIDER_TOKEN`), в файлах ключей нет.

## Про BI
В программе BI-система — **Навигатор** (Сбер). В учебных материалах используется Metabase —
открытая система с той же логикой сборки дашбордов; навыки переносятся 1:1.

## Про банковские кейсы
Папки `case_*` внутри шагов — учебные кейсы в банковском контексте (юристы, контакт-центр,
клиентские кластеры, продажи банковских продуктов). Все данные **синтетические**, сгенерированы
для обучения; совпадения с реальными клиентами и сотрудниками случайны. Пароли в docker-стендах —
учебные, действуют только на локальной машине участника.
