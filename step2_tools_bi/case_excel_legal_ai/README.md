# Excel-кейс: пилот ИИ для юристов в банке

В этой папке лежит практический кейс для модуля `Excel, BI и Python`.

## Что внутри

- `data/legal_ai_contract_review_raw.csv` - сырая выгрузка событий для импорта в Excel.
- `data/legal_ai_contract_review_training.xlsx` - учебная книга с формулами очистки, графиками «было/стало», сводным листом и финальной визуализацией.
- `artifacts/excel_before_after.png` - картинка для слайда про очистку.
- `artifacts/excel_pivot_placeholder.png` - картинка для слайда про сводную.
- `artifacts/excel_final_decision.png` - картинка для слайда с итоговым решением.
- `artifacts/data_category_map_legal_ai.svg` - схема Data Category Map для вводного слайда.

## Рекомендуемый сценарий показа

1. В Excel откройте `Данные -> Из текста/CSV` и загрузите сырую выгрузку.
2. Покажите размер файла: 82,104 строк.
3. Объясните два главных дефекта данных:
   - пропуски или поздние события закрытия;
   - искусственное раздувание длительности из-за нерабочего времени.
4. Откройте лист `02_Cleaning` и покажите формулы:
   - `next_open_same_employee`;
   - `corrected_close`;
   - `clean_work_minutes`.
5. Перейдите на `03_Before_After` и покажите, как после очистки тренд становится стабильным.
6. Откройте `04_Pivot_Summary` и покажите нативную сводную таблицу с цветовой шкалой по среднему времени.
7. Завершите на `05_Final_Visual`: все показатели на листе считаются формулами от очищенных данных, а нижняя граница доверительного интервала сравнивается с порогом 20%.
