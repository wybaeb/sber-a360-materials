# BI-кейс: обучение контакт-центра по речевой аналитике

В этой папке лежит локальный open-source BI-стенд на базе `Metabase` и `PostgreSQL`.

## Что именно установлено

- `Metabase` как конструктор виджетов и дашбордов.
- `PostgreSQL` как локальная база, куда загружается учебный набор данных.
- `Docker Compose` для запуска обоих сервисов одной командой.

## Данные

- Файл: `data/contact_center_speech_analytics.csv`
- Гранулярность: одна строка на сотрудника в одну неделю
- Покрытие: 48 сотрудников и 24 недели наблюдений

## Метрики на дашборде

- выручка от продаж
- ошибки скрипта, найденные ИИ
- ошибки, отклоненные супервайзером
- рекомендации, отправленные в обучение
- рекомендации, выполненные сотрудником
- индекс следования рекомендациям
- QA score

## Быстрый запуск

1. Запустите Docker Desktop.
2. Выполните `./run_metabase_case.sh`
3. Скрипт:
   - пересоберет датасет;
   - поднимет `postgres` и `metabase`;
   - настроит базу, карточки и дашборд;
   - откроет именно конструктор Metabase, а не только публичный просмотр.

## Что показывать в аудитории

1. Откройте главную страницу Metabase и войдите под учеткой из вывода скрипта.
2. Перейдите в дашборд `Дашборд обучения по речевой аналитике`.
3. Покажите 4 виджета:
   - выручка по неделям;
   - ошибки ИИ и отклонения супервайзера;
   - командный срез для коучинга;
   - связь рекомендаций и продаж.
4. Если хотите показать сборку виджета, откройте любую карточку:
   - `View the SQL` для SQL-запроса;
   - `Visualization` для смены типа графика;
   - `Add to dashboard` для добавления на экран.

## Полезные файлы

- `run_metabase_case.sh` - запуск стенда

- `artifacts/bi_dashboard_placeholder.png` - запасная картинка для слайдов
